# Architecture Decision Records

Architecture Decision Records (ADRs) preserve the context, decision, and
consequences of choices that materially shape Squad-Up.

## Status lifecycle

- **Proposed**: under discussion and not yet binding.
- **Accepted**: the current decision that implementation should follow.
- **Superseded**: replaced by a newer ADR; retained as historical context.
- **Rejected**: considered but not adopted.

Accepted ADRs should not be rewritten when the decision changes. Create a new
ADR, link both records, and mark the previous one as superseded.
